One demo app for the whole package

This window shows every appkit feature behind a single, borderless, cross-platform UI. Pick a section on the left - or read on.

  • Custom chrome: this bar is drawn by the page and dragged with -app-region.
  • Under the hood: the page is the embedded UI served from App.FS at the uniform app:// origin on every platform.

Bind - Go values, callable and readable from JS

One entry, one dotted name: a Go function is callable - a zero-argument one also reads as a value (await demo.clock), a one-argument one also accepts assignment (demo.mark = value); a [2]any{getter, setter} pair is a value whose state stays in Go - readable and writable (demo.theme), while a lone getter (demo.counter) or lone setter (demo.setp) binds read-only / write-only; any other JSON-encodable value is an immutable, frozen constant (demo.meta).

Autostart - launch at login (App.Autostart)

-

Registers this demo binary to start with your user session. The registration identifier comes from App.Name (App.ID when set); Enabled / Path / Backend report the current registration (per platform: XDG .desktop file, Windows Run registry value, macOS LaunchAgent / SMAppService). Takes effect at the next login. The self test enables and disables it again, leaving no registration behind.
